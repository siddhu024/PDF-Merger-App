# PDF-Merger-App
PDF Merger Web Application is a Flask-based web application that allows users to upload multiple PDF files, arrange them in the desired order, and merge them into a single PDF.

# PDF Merger Web Application

## Description

PDF Merger is a Flask-based web application that allows users to upload multiple PDF files and merge them into a single PDF. The application provides a simple interface for selecting files and downloading the merged document.

## Features

- Upload multiple PDF files
- Merge PDFs into a single document
- Download the merged PDF
- Simple and user-friendly interface
- Fast and efficient processing

## Technologies Used

- Python
- Flask
- HTML
- CSS
- PyPDF2 (or pypdf)

## Installation

1. Clone the repository.

```bash
git clone https://github.com/your-username/pdf-merger.git
```

2. Move to the project directory.

```bash
cd pdf-merger
```

3. Install the required packages.

```bash
pip install -r requirements.txt
```

4. Run the application.

```bash
python app.py
```

5. Open your browser and visit:

```
http://127.0.0.1:5000
```
